## 1. 关键事件加权正式结论

三套事件加权模型均从随机初始化训练，不使用lag168、XGBoost输入、教师或残差。完整连续MPC
结算结果为：

- 日均净收益：`221.02 USD/节点·日`；
- 稳健XGBoost：`292.29`；
- 配对差值：`-71.27`，7日块Bootstrap 95%区间`[-108.81, -42.22]`；
- 最大回撤：`500.21`，差于XGBoost的`206.07`；
- 去掉最好5日后的收益：`140.87`，XGBoost为`210.51`；
- 重要价差方向准确率：`52.30%`，XGBoost为`65.23%`。

事件加权相对纯任务专属损失把重要价差方向从约`47.77%`提高到`52.30%`，但仍远低于基线；
同时收益从纯新三模型的`234.19`下降到`221.02`，回撤从`177.68`升到`500.21`。因此仅增加
尖峰、大价差和符号反转样本权重不能解决结构性价差错误，本路线不补多seed、不进入最终模型。

全部三套checkpoint、候选、完整结算和日志已回收到
`data/checkpoints/cloud_eventweight_20261010/`与`data/results/`，逐文件SHA256与云端一致。

## 2. 为什么检查pre-encoder节点条件化

旧Global模型只在五条历史流编码、融合之后加入节点/市场embedding，因此共享历史编码器提取模式时
不知道当前节点身份。`pre_encoder`让身份向量在每条流的输入投影后、进入编码器前生效，其余网络
宽度、损失、学习率、训练预算和数据切分不变。这是结构消融而不是调参，也可以原样应用于其他市场。

考虑到RT-at-DA是当前主要瓶颈，本地RTX 4070先只训练该分支。正式结论以早停后的完整验证和
下游结算为准；若RT-at-DA预测本身不能超过任务专属模型，则不继续训练另两支，避免无效计算。

## 3. 显式价差参数化

现有DA和RT-at-DA分别拟合绝对价格，但电池日前计划实际读取`p_DA - p_RT|DA`。两个独立的价格
误差即使各自MAE下降，也可能叠加为错误的价差方向。新增可选参数化：

```text
冻结的自有DA模型 ──> p_DA ───────────────┐
                                               ├─> p_RT|DA = p_DA - predicted spread
RT-at-DA历史编码器 ──> predicted DA-RT spread ┘
```

关键合同：

- 上游只使用同一D-1起报时点产生的自有DA预测，不读取未来DA真值；
- 真实DA和RT只在训练损失中构造价差标签，不进入模型`forward`；
- 价差中心和尺度来自2020—2022逐节点DA/RT统计量；
- RT-at-DA继续使用伪Huber，但监督对象改为标准化价差，不新增可调损失权重；
- 推理时RT价格由DA预测和价差预测唯一重建，代数关系可直接审计；
- 上游DA checkpoint路径和SHA256写入元数据，来源改变时禁止静默复用预测缓存；
- 不使用ERCOT固定尖峰阈值或XGBoost，结构可迁移到CAISO、NYISO和PJM。

本地已完成模型、数据标签边界、训练入口、价差诊断和预测导出改造。2节点一轮smoke已打通完整
链路；smoke数值不参与排名。针对性测试和全仓测试均通过，正式15节点训练待本地GPU从
`pre_encoder`消融释放后开始。

## 4. 冻结判断顺序

1. 完成本地RT-at-DA `pre_encoder`早停，若MAE/价差方向不改善则淘汰该结构；
2. 正式训练显式价差RT-at-DA，只改变预测对象与代数参数化；
3. 与当前最佳自有DA epoch 5、滚动RT epoch 5组成系统，运行同合同完整结算；
4. 同时报告RT-at-DA MAE、价差MAE、全体/重要价差方向、收益、配对区间和回撤；
5. 只有显著缩小相对XGBoost差距才考虑多seed或三模型盈利联合训练；
6. 2024不用于本轮结构选择，2025继续锁定。
