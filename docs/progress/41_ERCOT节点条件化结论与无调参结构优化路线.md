# ERCOT节点条件化结论与无调参结构优化路线

> **结果适用范围修订**：本文件的 `pre_encoder` 结论明确针对已知节点/市场身份条件化模型。它证明
> 节点身份提前进入编码器对已见 ERCOT 节点可能有经济价值，但不能证明未见市场零样本迁移；不能把
> `271.63` 或本文件后续身份条件化结果当作通用模型结果。

> 历史状态：保留节点条件化、显式价差和文献路线证据；当前冠军与执行顺序已由`42`和`43_当前结论与实验总账.md`取代。

> 日期：2026-10-10  
> 数据边界：2020—2022训练，2023内部验证；2024/2025均未用于本轮开发。  
> 目标：自有DA、RT-at-DA、滚动RT三模型超过强基线，并在结构冻结后验证跨市场泛化。  
> 原则：只做有失败归因和经济含义的结构改动，不通过搜索学习率、网络宽度、层数或损失权重优化结果。

## 1. pre-encoder节点条件化的完整结论

本轮只重新训练RT-at-DA的`pre_encoder`结构；DA和滚动RT复用任务专属损失候选。与旧模型相比，
唯一结构差异是节点/市场身份在每条历史流进入编码器前生效。完整15节点、362日连续双结算结果为：

- 最佳组合：`da_entitylocal1__rt_at_da_entitylocal0__rt_entitylocal0`；
- 日均净收益：`271.63 USD/节点·日`；
- 旧最佳自有系统：`241.70`；
- 稳健XGBoost：`292.29`；
- 相对XGBoost差值：`-20.66`，7日块Bootstrap 95%区间`[-42.00, 0.41]`；
- 最大回撤：`196.86`，略好于XGBoost的`206.07`；
- 去掉最好5日后的收益：`182.19`，XGBoost为`210.51`；
- 正收益日比例：`51.38%`，明显低于XGBoost的`79.28%`。

RT-at-DA MAE仍为`46.64`，差于任务专属模型第一候选的`41.18`，重要价差方向准确率也只有
`46.94%`，低于XGBoost的`65.23%`。因此本结构不能宣称击败基线，也不补多seed；但它使自有系统
收益提高约`29.93 USD/节点·日`，将相对基线差距从`50.59`缩小到`20.66`，说明节点身份在编码前
参与特征抽取具有真实经济价值。普通价格MAE不能替代完整收益结算。

正式结果：

- `data/results/global_entitypre_local_continuous_mpc_v1.json`
- `data/results/global_entitypre_local_summary_v1.json`

## 2. 文献证据与项目取舍

### 2.1 直接学习DA/RT价差：已完成，未晋级

Wang等（2024）在ERCOT两结算市场中直接预测实时与日前价差，并用交易收益评价模型，而不是只比较
两个绝对价格预测。这与本项目的日前电池决策直接读取`DA - RT-at-DA`一致：

- https://arxiv.org/abs/2412.00062

因此本轮训练并结算了已经实现、通过无泄漏测试的结构：

```text
冻结的自有DA预测 - RT-at-DA模型预测的显式价差 = RT-at-DA价格预测
```

相对现有任务专属模型，网络宽度、层数、学习率、训练预算和伪Huber损失均不改变；只改变被预测的
经济量。价差中心与尺度只由2020—2022训练期逐节点统计量产生，上游DA checkpoint及SHA256写入
元数据。这是可解释结构消融，不是调参。

2026-10-11完成seed 0正式训练、六套候选预测导出，以及15节点、362日的连续双结算。最佳组合为
`da_spreadfactor1__rt_at_da_spreadfactor0__rt_spreadfactor0`，但未通过晋级门槛：

- RT-at-DA MAE：`39.85`，好于旧任务专属候选的约`41.18`，但差于XGBoost的`35.30`；
- 重要价差方向准确率：`61.39%`，低于XGBoost的`65.23%`；
- 日均净收益：`150.31 USD/节点·日`，XGBoost为`292.29`；
- 配对收益差：`-141.98`，7日块Bootstrap 95%区间`[-231.12, -73.13]`；
- 最大回撤：`365.55`，XGBoost为`206.07`；
- 去掉最好5日后的收益：`78.84`，XGBoost为`210.51`。

失败原因不是“直接价差没有意义”，而是当前标准化与伪Huber训练产生了明显的**价差幅度收缩**：
预测绝对价差均值仅`6.80`，真实值为`34.89`；预测q95仅`20.31`，真实q95为`101.68`；价差
Pearson相关系数只有`0.037`。它提高了一部分方向判断，却几乎没有恢复可用于电池调度的价差幅度，
所以MAE改善没有转化为收益。该候选不补多seed，下一步转向基础价格与物理压力门控的稀缺残差分解。

正式结果：

- `data/results/global_spreadfactor_continuous_mpc_v1.json`
- `data/results/global_spreadfactor_summary_v1.json`
- `data/results/global_spreadfactor_predictions_v1/`

### 2.2 基础价格加稀缺残差：显式价差失败后的下一候选

Selcuklu（2026）的PGRRN把电价写成“线性基础价格 + 物理条件门控的非线性稀缺/拥塞残差”，并将
门控输入限制为负荷、净负荷及日历等物理变量；其五市场实验报告优于XGBoost、DNN和LEAR：

- https://doi.org/10.1016/j.asoc.2026.115931

该方法与本项目关键事件加权失败的归因一致：尖峰不是应被简单加权的孤立异常，而可能是供需紧张
引发的另一价格状态。若显式价差仍未缩小差距，下一结构只加入如下可审计分解：

```text
预测 = 基础通道 + sigmoid(物理压力门控) × 稀缺残差通道
```

门控禁止读取未来价格和节点专属价格尖峰，只能读取起报时真实可用的负荷、风光、历史压力和日历；
稀缺残差输出层从零初始化，使模型先等价于基础通道，再学习基础通道无法解释的残差。

### 2.3 外生变量注意力：有发布时刻证据后再做

TimeXer（NeurIPS 2024）使用内生价格patch与外生变量之间的交叉注意力；NBEATSx在多个年份和市场的
电价任务中使用可解释基展开与外生变量。这两项研究支持把供需驱动与价格历史分开建模：

- https://proceedings.neurips.cc/paper_files/paper/2024/hash/0113ef4642264adc2e6924a3cbbdf532-Abstract-Conference.html
- https://doi.org/10.1016/j.ijforecast.2022.03.001

但当前统一表中的未来天气预测没有可审计的`forecast_issue_time`，不能证明它在各市场关门前已发布。
所以本轮不接入未来天气、未来实际负荷或未来实际风光，不用潜在泄漏换取表面提升。

### 2.4 跨市场分布变化：先审计，暂不盲加RevIN

近期研究把时间、空间和条件分布变化区分开，并指出常用RevIN并非总是稳健；另有研究显示均值/标准差
会被极端值污染，在含尖峰序列上简单RevIN可能灾难性退化，而中位数/MAD更稳健：

- https://arxiv.org/abs/2603.11869
- https://arxiv.org/abs/2510.04667

ERCOT价格有极端尖峰，因此不把RevIN作为无条件插件。后续只做训练期中位数/MAD诊断，并在四市场
共同协议下比较“固定逐节点标准化”和“稳健逐样本标准化”；不根据2024/2025结果反选。

### 2.5 为什么暂不再做收益损失权重搜索

决策导向学习文献确认MAE最低不等于电池收益最高，但本项目先前的零阶收益微调已经显示简单改变
收益权重不能解决表示和价差方向问题。当前先修正预测对象与结构，只有结构候选在冻结结算中接近或
超过基线后，才考虑单一、预先固定的盈利微调，不搜索权重。

## 3. 冻结的跨市场泛化合同

ERCOT只用于结构开发；结构冻结后，按完全相同的模型和损失验证CAISO、NYISO和PJM：

1. 每市场先等权、市场内再节点等权，避免PJM节点多而支配训练；
2. 每个市场分别与自己的Seasonal、LEAR和稳健XGBoost比较；
3. 同时报每市场MAE、最差市场MAE和价差方向，不用四市场均值掩盖失败市场；
4. 不为某个市场改变层数、宽度、学习率、损失权重或阈值；
5. 外部市场结算规则未冻结前只比较预测，不复制ERCOT罚金后声称盈利；
6. 2024只作一次冻结外层验证，2025继续锁定到最终模型。
