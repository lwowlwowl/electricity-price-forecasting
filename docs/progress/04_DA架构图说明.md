# 04｜DA架构图说明

可编辑图：`docs/da_model_architecture.drawio`。

从左到右阅读：

1. 五条历史流和目标日已知日历；
2. 五个独立Stream Encoder；
3. 同小时来源交互、来源加权汇聚、168步时间记忆；
4. 24个DA query通过Cross-Attention读取memory；
5. DA价格头、固定HardTopK、BESS收益和两类损失。

颜色含义已经画在图内：蓝色是历史数据，绿色是未来已知条件或输出，紫色是可训练模型，橙色是固定策略/物理执行，红色是监督或损失。

图中明确标了两个限制：未来实际负荷/风光/RT价不进入模型；当前收益是DA-only代理，不是计划SOC已经完整检查过的双结算收益。

校验结果：0 error、0 warning、0 crossing、0 overlap。当前机器没有draw.io命令行程序，所以没有自动导出PNG；`.drawio`可直接在diagrams.net或draw.io桌面版打开和继续编辑。
