# 06｜RT模型架构图与训练图说明

可编辑图：

- `docs/rt_model_architecture.drawio`；
- `docs/rt_training_loop.drawio`。

图从左到右展示每个实时小时的完整循环：

1. 读取截至上一完整小时的五条历史流；
2. 五个独立Encoder编码；
3. 同小时来源交互并汇聚成168步memory；
4. 4个query接收已公布DA价和日历，预测未来4小时RT价；
5. 模型边界到`p_RT [B,4]`为止；
6. 模型外分别标出正式`rt_only/HardTopK`和候选“4小时约束MPC”；
7. 两种方式都只执行第1步、更新真实SOC，并在下一小时重新预测。

模型图特别区分“未来已知DA价/日历”和“未来实际信息”，也标明DA与RT模型
不共享权重。MPC不会改变Transformer输入、Encoder、Decoder或价格头，只改变模型
输出之后的动作规划。

训练图同时保留两种训练含义：正式基线使用Huber；MPC候选在其checkpoint上加入
零阶代理损失。图中明确标注候选在验证集获胜、测试集失败，因此没有覆盖正式方案。

两张图均是可编辑`.drawio`，本轮结构校验均为
`0 error / 0 warning / 0 crossing / 0 overlap`。机器没有draw.io命令行程序，
因此未自动导出PNG。
