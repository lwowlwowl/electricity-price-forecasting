# 06｜RT架构图说明

可编辑图：`docs/rt_model_architecture.drawio`。

图从左到右展示每个实时小时的完整循环：

1. 读取截至上一完整小时的五条历史流；
2. 五个独立Encoder编码；
3. 同小时来源交互并汇聚成168步memory；
4. 4个query接收已公布DA价和日历，预测未来4小时RT价；
5. HardTopK(1,1)产生候选动作，只执行第1步，更新真实SOC；
6. 下一小时重新预测。

图中特别区分“未来已知DA价/日历”和“未来实际信息”，也标明DA与RT模型不共享权重。右下角黄色提示说明当前RT收益不含DA头寸，不能当作双结算收益。

校验结果：0 error、0 warning、0 crossing、0 overlap。与DA图相同，由于机器没有draw.io命令行程序，本轮只交付已经结构校验的可编辑`.drawio`文件。
