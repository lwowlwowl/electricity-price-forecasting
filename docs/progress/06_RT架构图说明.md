# 06｜RT模型架构图与训练图说明

可编辑图：

- `docs/rt_model_architecture.drawio`；
- `docs/rt_training_loop.drawio`。

图从左到右展示每个实时小时的完整循环：

1. 读取截至上一完整小时的五条历史流；
2. 五个独立Encoder编码；
3. 消融后选定的F0将同小时五来源concat投影，并通过残差MLP形成168步memory；
4. 4个query接收已公布DA价和日历，预测未来4小时RT价；
5. 模型边界到`p_RT [B,4]`为止；
6. 模型外用固定`rt_only/HardTopK`生成实时候选动作；
7. 只执行第1步、更新真实SOC，并在下一小时重新预测。

模型图特别区分“未来已知DA价/日历”和“未来实际信息”，也标明DA与RT模型
不共享权重。历史MPC候选没有晋级，不再占据当前模型主图。

训练图现描述融合消融的正式流程：纯Huber负责更新模型；每个epoch在3个DA F1
与3个RT-at-DA F0组成的9个冻结参考组合下计算完整双结算验证收益。F0三seed均值
108.56，高于F1的101.37；F1b取消softmax加权和后回升到104.21，但仍低于F0。
F0减F1的配对95%区间为[1.94,14.15]，F0减F1b为[-0.39,9.75]。
因此部署仍选F0且不补F2；F1b只证明原汇聚瓶颈解释了部分、而非全部收益差。

两张图均是可编辑`.drawio`，本轮结构校验均为
`0 error / 0 warning / 0 crossing / 0 overlap`。机器没有draw.io命令行程序，
因此未自动导出PNG。
