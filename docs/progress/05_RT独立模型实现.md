# 05｜独立RT模型实现

## 滚动时间合同

在每个小时`t`开始时：

- 历史输入是`[t-168,t)`，最后一个输入是`t-1`完整小时；
- 预测RT价格`[t,t+4)`，共4个小时；
- 固定策略根据4小时预测产生候选动作，但部署/回测只执行第1步；
- 到`t+1`后，用新信息重新构造168小时历史并重新预测；
- 真实SOC连续维护，不因模型重新预测而重置；每日只重置累计放电上限。
- 训练/验证/测试日期边界按ERCOT当地时间解释，测试第一窗从2025-07-01 00:00 CDT开始，不会提前落到6月30日晚间。

数据代码：`src/decision_aware/dataset_rt.py`。

实际审计得到43,677个训练窗口、4,340个验证窗口和8,057个测试窗口。
第一测试窗的历史是2025-06-24 00:00到2025-06-30 23:00 CDT，预测并执行2025-07-01 00:00开始的窗口。

目标4小时的已公布DA价格和日历可作为未来已知条件。未来实际负荷、风光和RT价不会进入输入。第一版假定ERCOT按正常发布时间公布目标小时DA价格；若团队以后提供异常发布日规则，需要再给已知DA价增加availability mask。

## 模型结构

代码：`src/decision_aware/model_rt.py`；配置：
`configs/decision_aware/rt_ercot_v1.yaml`。

RT模型沿用“同小时五来源注意力”的代码结构，但实例化自己的全部参数，和DA模型不共享可训练权重。4个query接收`已知DA价 + 日历`的逐小时投影，再Cross-Attention读取168步memory。输出只有`p_rt [B,4]`，没有DA头。

## 训练与滚动收益诊断

训练入口：`scripts/decision_aware/train_rt.py`。当前第一版使用Huber监督训练，但checkpoint按验证集RT-only滚动平均日收益选择。回测代码 `src/decision_aware/backtest_rt.py`连续维护SOC，只执行每个窗口的第一个动作。

CPU smoke使用71,362参数、32个训练/验证/测试窗口跑了2个epoch，成功保存：

- `data/results/rt_transformer_smoke.json`
- `data/checkpoints/rt_independent_v1/pilot_LZ_LCRA_best_rolling_revenue_smoke.pt`

smoke验证平均日收益为-49.20，测试为-95.17。这只说明未训练充分的小模型链路能运行，不代表正式模型水平。

2026-09-28又在根目录`.venv`用RTX 4070完成2个epoch真实数据CUDA smoke，4小时预测、只执行第一步、连续SOC回测和按滚动收益保存checkpoint均正常结束。结果在`data/results/rt_transformer_cuda_smoke.json`；数值仍不作模型结论。

## 当前边界

RT收益是单市场诊断，没有接入已经锁定的`u_DA`，所以不是双结算最终收益。
RT训练目前也没有零阶决策代理损失。下一阶段必须先由团队确认“独立DA输出怎样锁定并传给RT训练/回测”，再做双结算decision-aware训练，不能私自创造接口后宣称完成。
