# 多市场阶段结论与实验总账

> 阶段状态：已冻结。基线数值以仓库根目录 `BASELINES.md` 和
> `configs/decision_aware/baseline_registry_v1.json` 为唯一来源。本页只解释实验演进，
> 不再承担活跃 TODO。

## 统一口径

- 经济评价统一在 ERCOT 15 节点上计算节点等权日均净收益；
- “多市场”描述训练数据，不表示把四个市场利润混在一起平均；
- 三条价格腿为 DA、RT-at-DA 和 rolling RT；
- 结算固定使用 DA LP、rolling RT MPC、连续 SOC、退化成本和偏差罚金；
- MAE 与收益分别报告，不允许用低 MAE 替代经济优势；
- 2023 用于开发与选模，2024 只作冻结确认，2025 是一次性锁定测试。

## 冻结基线

| 年份 | 角色 | 最强系统 | 收益（USD/节点·日） |
|---|---|---|---:|
| 2023 | 同数据 LOMO 开发基线 | pooled LOMO XGBoost | **418.0649** |
| 2024 | 时间外确认比较器 | 逐节点 XGBoost | **90.6909** |
| 2025 | 预注册纯基线 | DLinear | **61.5253** |

2023 的 pooled LOMO XGBoost 与无 ID Transformer 一样，只使用 CAISO、NYISO、PJM
2020—2022，完全排除 ERCOT 训练标签。逐节点 XGBoost 看过 ERCOT 历史标签，只能作为
目标市场监督比较器。2025 router 不是预注册纯基线，但后续方法仍需并列报告与它的差异。

## 无ID Transformer结论

### 2023开发

- seed 0：377.8381；
- 三 seed 等权预测集成：407.1667；
- pooled LOMO XGBoost：418.0649；
- 集成相对公平基线差 -10.90，7日块95%区间 `[-28.07, 7.43]`。

Transformer 在 12 项市场—任务 MAE 中赢 pooled XGBoost 9 项，但没有形成显著收益
优势。较小价格误差不能改写经济结论。

### 2024冻结确认

无 ID Transformer seed 0 为 73.3756，逐节点 XGBoost 为 90.6909；差 -17.32，
配对区间 `[-30.86, -5.06]`。2023 的点估计优势未跨年保持，因此不得回到 2023
继续挑权重或 seed。

### 2025锁定测试

四市场 2020—2024 重训后的无 ID Transformer 三 seed 集成为 28.0398，低于
pooled XGBoost 44.4290、逐节点 XGBoost 59.9892 和 DLinear 61.5253。相对 pooled
XGBoost 的配对差为 -16.39，7日块区间 `[-23.19, -10.05]`，预注册分类为
`no_superiority`。

预测侧，Transformer 相对六个覆盖三任务的完整基线在四市场×三任务 12 项 MAE 中
逐项最低；LEAR 只覆盖 DA 与 RT-at-DA，8项中 LEAR 胜5项、Transformer胜3项，
不属于“完整三腿12/12”结论。最终可写为“统一预测优势成立，经济优势不成立”。

## 已关闭的主要路线

| 路线 | 结论 |
|---|---|
| 带节点/市场 ID 的经济状态头 | 只能表示训练中已见实体，不是新市场零样本模型 |
| 稳定 Global 基础模型 | 2023收益192.83，低于强XGBoost |
| 简单连续MPC收益权重 | 没有修复价差表达问题 |
| lag-168残差锚点与价差损失 | 部分点估计改善，但区间、回撤或多seed门槛失败 |
| 关键事件加权 | 收益221.02且风险恶化，简单加权不足以修复尖峰 |
| 显式价差回归/方向强制 | 价差幅度继续收缩或错误翻转普通小时 |
| DA q99、Beta校准与条件GPD | 多市场守门指标0/3通过，不进入ERCOT结算 |

这些结果用于避免重复实验，不能重新包装为新基线。

## 仍然有效的工程成果

- 四市场起报时刻、无未来信息和缓存身份隔离合同；
- 无 ID、context-robust 归一化和留一市场训练协议；
- 三个独立价格模型及完整 DA LP + rolling RT MPC 结算链；
- 统一的块 bootstrap、节点覆盖、尾部收益和 SOC 审计；
- 2025归档哈希与一次性评价记录。
