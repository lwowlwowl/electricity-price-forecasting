# 盈利差诊断与经济价差协调头

> 日期：2026-10-20  
> 协议：2023拟合、2024冻结确认；2025只作固定跟进，`selection_allowed=false`。  
> 性质：原2025正式测试之后的固定跟进；`selection_allowed=false`  
> 状态：执行完成，路线冻结，不再根据2025调参

## 1. 诊断与跨年确认

2025既有系统的逐腿替换显示，只换 DLinear DA 和只换 DLinear RT-at-DA 分别带来
`+18.44/+15.25 USD/节点·日`；Transformer 的日内排序较好，但预测
`DA-RT-at-DA` 绝对价差只保留真实幅度约50%，超过6美元电池盈亏平衡阈值的比例
低于 DLinear。问题由此定位为跨任务经济价差不协调，而不是单一 DA MAE。

协调头冻结价格骨干，用6美元阈值将小时分成 DA高、中性、RT高，再由低参数线性
分类和非负幅度回归校准价差。2023拟合期收益差为-1.28且区间跨0；不改参数的2024
确认把收益从73.38提高到94.59，差`+21.21 [8.07, 41.30]`，15/15节点改善，
删除改善最高10日后仍为+6.01。该层提高经济价值但恶化价差MAE，因此不是更准确的
价格预测器。

## 2. 2025固定跟进

协调头的参数、6美元阈值和幅度公式均沿用2023拟合、2024确认版本。最终三seed DA和滚动RT预测不变，
只用协调后的价差重构RT-at-DA，再运行完全相同的连续DA LP、逐小时RT MPC和双结算账本。

| 2025系统 | 净收益（USD/节点·日） | 相对原Transformer |
|---|---:|---:|
| 原Transformer三seed集成 | 28.04 | — |
| **冻结经济价差协调头** | **34.20** | **+6.16** |

配对7日块95%区间为`[2.97, 9.47]`；15/15个节点平均收益均未下降，节点差值为`+0.05`至
`+34.05`。删除改善最高1、5、10日后，平均差仍为`+5.54/+4.24/+3.28`。因此盈利改善不是单个
节点或少数日期造成。

## 3. 收益与成本分解

| 指标（USD/节点·日，吞吐量除外） | 原Transformer | 协调头 | 变化 |
|---|---:|---:|---:|
| DA计划腿 | 51.64 | **61.44** | **+9.80** |
| RT修正腿 | **2.56** | 2.14 | -0.41 |
| 退化成本 | **15.34** | 19.91 | +4.57成本 |
| 偏差罚金 | 10.82 | **9.48** | **-1.34成本** |
| 日吞吐量（MWh） | 2.69 | 3.49 | +0.80 |
| 最终净收益 | 28.04 | **34.20** | **+6.16** |

协调头通过增加具有经济价差的DA动作提高计划收益；它承担了更高退化成本，没有规避费用。正收益日
比例由`65.2%`提高到`76.0%`，但宏观最大回撤由`140.95`增加到`163.28 USD`，说明风险并非所有
维度都改善。

## 4. 盈利是否来自尾部

冻结阈值只由ERCOT 2020—2024历史计算。为避免重复计数，小时按“负价→正尖峰→最高1%绝对价差→
最高5%剩余价差→普通时段”的优先级互斥划分。

| 2025时段 | 对总收益差的贡献（USD/节点·日） |
|---|---:|
| 负价 | -0.08 |
| 正尖峰 | -0.32 |
| 最高1%绝对价差（排除前两类后） | 0.00 |
| 最高5%剩余极端价差 | **+1.71** |
| 普通时段 | **+4.84** |
| 合计 | **+6.16** |

2024冻结确认中，正尖峰和其他极端价差合计贡献`17.17/21.21`，约81%；但2025的改善主要来自普通
时段和较宽口径的极端价差，正尖峰与负价没有改善。因此准确结论是：

> 经济价差协调能够跨年稳定提高完整净收益，并在2024主要从尾部获益；但它没有稳定解决2025正尖峰
> 和负价预测，不能称为尾部预测模型。

## 5. 与冻结强基线比较

| 系统 | 2025净收益（USD/节点·日） |
|---|---:|
| DLinear | **61.53** |
| 逐节点XGBoost | 59.99 |
| pooled all-market XGBoost | 44.43 |
| TimesFM-2.5 LoRA | 35.74 |
| 冻结经济价差协调头 | 34.20 |
| 原Transformer集成 | 28.04 |

协调头相对原Transformer显著提高`6.16`，但仍低于公平pooled XGBoost `10.23`，低于DLinear
`27.33`，也略低于TimesFM-2.5。因此论文不能改写为“Transformer盈利超过强基线”。可以主张的是：

1. 原Transformer的跨任务价差不足确实限制盈利；
2. 一个只有线性状态分类和非负幅度回归的可解释后训练层，可在2024和2025连续提高完整净收益；
3. 该改进不依赖修改LP/MPC、免除成本或事后选择seed；
4. 仍存在与树模型和DLinear的经济价值差距，正尖峰/负价也尚未解决。

## 6. 当前决定

该机制保留为`interpretable profit calibration`，而不是价格预测头或零样本模型。到此停止：不再用2025
调整分类器、阈值、幅度或特征。原2025一次性测试仍是正式主结果，本页作为透明的固定跟进研究单独
报告。
