# ERCOT多节点三模型残差锚点与价差训练结论

> **通用性边界**：本文件使用已知实体身份条件，负结果和机制诊断仍有效，但不构成无 ID 通用性证据；详见第46号文档。

> 日期：2026-10-10  
> 阶段：2020—2022训练、2023内部验证；2024未重新用于本轮调参，2025完全未读取。  
> 结论：本轮没有得到可晋级的最终三模型；稳健XGBoost仍是必须击败的基线。

## 1. 本轮实际完成内容

AutoDL RTX 4090D完成以下三段实验，所有排名均使用同一套连续DA计划、锁定DA、逐小时RT
MPC、偏差罚金、退化成本、SOC与功率约束：

1. 训练DA lag168残差模型和RT-at-DA lag168残差模型，各保留预测指标最好的三个epoch；
2. 将原始lag168锚点也纳入候选，与冻结的稳定Global RT组成16个候选，并加入稳定Global、
   Seasonal和稳健XGBoost，共19个系统完成15节点2023全年结算；
3. 从稳定Global三模型出发，完成四组只更新各自价格输出头的联合价差/盈利训练；
4. 对原始锚点与稳定Global尝试11个不使用真实标签的混合、方向一致门控、极值门控和价差截断候选。

原始数据Parquet的本地SHA256仍为
`43c2eb4b4c5c8ce467113f67744d9784ccb591e1febe0423642f363e7369c19d`。

## 2. lag168残差训练结果

DA三个训练候选的2023 MAE分别为`47.98 / 48.41 / 48.44`；原始lag168锚点约为`47.99`。
训练基本没有改善DA锚点。RT-at-DA三个训练候选的MAE为`54.86 / 55.17 / 56.14`，均明显
差于原始锚点的`50.60`，也差于稳定Global的约`43.66`。

完整结算中，所有训练后残差组合均低于稳健XGBoost。训练后最好组合为
`lagda2 + 原始lag168 RT-at-DA + 稳定Global RT`，仅`254.55 USD/节点·日`。
因此，“围绕lag168直接学习残差”这条训练路线淘汰，不补seed、不进入2024。

## 3. 原始锚点组合为何不能算胜出

`原始lag168 DA + 原始lag168 RT-at-DA + 稳定Global RT`得到最高点估计：

- 平均净收益：`297.49 USD/节点·日`；
- 稳健XGBoost：`292.29`；
- 配对差：`+5.20`，约`+1.8%`；
- 7日块Bootstrap 95%区间：`[-46.16, 57.29]`，跨0；
- 正收益日比例：`65.75%`，低于XGBoost的`79.28%`；
- 宏观累计收益最大回撤：`7272.07 USD`，XGBoost仅`206.07 USD`；
- 最差单日：`-7040.66 USD/节点`，XGBoost为`-206.07`；
- 日均偏差罚金：`32.71 USD`，XGBoost为`9.87`。

该组合的均值由少数尖峰日显著抬高，前5日贡献总收益的`38.45%`；去除前5个尖峰日后，
均值仅`185.68`，而XGBoost仍有`210.51`。所以它只是高方差候选，不是稳健胜出，更不是
可以锁定的最终模型。并且两路原始lag168锚点是季节性规则，不是训练后的DA/RT-at-DA模型，
本身也不满足“最终三套模型必须自己训练”的目标。

## 4. 三模型联合价差训练

四组候选均保留三套独立模型，只在同一步用共同的价格、价差方向、价差幅度和完整MPC收益
信号更新三个价格输出头。最好的是`jointspread_c`：

- 稳定Global起点：`192.83 USD/节点·日`；
- `jointspread_c`：`221.77`，提高`28.94`；
- 相对XGBoost仍差`70.52`；
- 配对7日块95%区间`[-123.68, -32.94]`，完全低于0；
- 正收益日比例`56.35%`，宏观累计收益最大回撤约`2370.70 USD`。

这说明显式价差监督比上一轮单纯盈利微调更有效，但只更新输出头仍不足以弥补基础表示差距。
`jointspread_c`作为诊断性最佳checkpoint保留，不晋级、不进入2024。

## 5. 门控与价差截断

门控不依赖XGBoost，也不读取真实标签，只组合原始lag168锚点与稳定Global预测。收益最高的
`clip200`和`clip100`分别为`296.66`与`295.80`，但最大回撤分别为`7289.78`和`7290.20`，
偏差罚金也仍约`32.7`，没有修复尾部风险。能明显抑制极值的门控只获得约`244—266`，又低于
XGBoost。因此门控/截断支线也不晋级。

## 6. 冻结结论与下一步

本轮可以确认：

- lag168提供了有价值的价差方向信息，但直接残差训练会破坏它；
- 简单输出头联合微调能把Global从`192.83`提高到`221.77`，但架构表示能力仍是主要瓶颈；
- 追求少数尖峰带来的均值会制造不可接受的回撤、偏差罚金和日收益集中度；
- 目前没有自己的三模型在收益、置信区间和尾部风险上同时击败稳健XGBoost。

下一轮应停止在旧输出头上继续扫权重，改为训练编码器级候选：共享市场特征编码器、节点嵌入、
三个任务独立预测头，并用“常规时段 + 尖峰 + 价差反转”分层采样。先在2023检查每个任务的
MAE、关键价差方向、尖峰召回和节点异质性，再对合格候选做完整盈利微调。2024继续保持冻结，
直到形成预先固定且明显强于当前Global的内部候选；2025仍不得读取。
