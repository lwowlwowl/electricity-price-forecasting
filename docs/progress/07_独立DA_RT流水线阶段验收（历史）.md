# 07｜独立DA/RT流水线阶段验收（历史）

> 本文记录第一轮独立DA与滚动RT流水线的阶段状态，不是项目当前最终状态。
> 当前结论见文档23—24；团队对DA头寸性质、偏差罚金和期末价值仍未最终确认。

## 已完成

- DA固定D-1 10:00样本合同、目标日日历输入和无未来实际协变量检查；
- 完整DA周期、ExtraTrees、XGBoost、GRU基线及统一收益评价；
- 独立DA Transformer、独立损失、训练入口、收益选模和smoke checkpoint；
- 可编辑DA架构图，结构校验无错误或警告；
- 独立RT滚动数据集、Transformer、训练入口和连续SOC回测；
- DA与RT参数不共享的自动测试；
- 可编辑RT架构图，结构校验无错误或警告。
- 根目录`.venv`已验证CUDA训练，项目DA模型可在RTX 4070 Laptop上完成前向、
  反向和参数更新。
- 独立DA Transformer已完成三个随机种子的正式训练；当前平均测试代理收益
  94.96，尚未超过XGBoost的114.79。
- 独立RT Transformer已完成三个随机种子的正式CUDA训练；后续完整双结算
  验证选模也选中seed 2。
- 已加入独立计划SOC，并完成锁定24小时DA计划、逐小时滚动RT、真实SOC连续和
  双结算分项账本。
- 固定同一RT后，Transformer DA双结算平均日收益83.13，低于XGBoost DA的
  94.35；预测MAE更低没有转化成更高收益。
- 已确认局部`track_adjust`策略不可靠，并完成4小时约束MPC、三seed收益微调和
  完整双结算复核；MPC验证集提高但测试集下降，因此仍冻结`RT seed 2 + rt_only`。
- 根目录`pytest`默认只收集本项目`tests/`，不再误扫`external/`上游测试或缓存。

所有新增代码只读取`data/markets`。没有修改其中任何Excel/Parquet；没有修改`external/`；没有执行`git add`或`git commit`。

本阶段测试结果为`51 passed`。RT模型图和训练图已同步正式基线与MPC候选的边界。

2. 团队确认DA物理计划/金融头寸、偏差罚金与期末库存合同，然后冻结正式收益口径；
   当前仍只冻结了模型侧保守口径，团队确认尚未完成。

   不能继续使用已经看过的测试期调参。
4. 再推进四市场泛化、稳健性、统计区间和论文交付。
