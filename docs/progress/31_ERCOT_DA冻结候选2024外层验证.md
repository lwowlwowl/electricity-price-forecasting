# ERCOT DA冻结候选：2024外层验证

> **通用性边界**：这是带已知实体身份条件的历史外层验证，不能替代无 ID 留一市场验证；详见第46号文档。

> 本页只记录2024外层验证。2025锁定回顾测试尚未读取。

## 冻结方案

- DA：Global F1，seed 0/1/2逐小时中位数；随后使用2023已冻结的公式 `1.15 × XGBoost - 0.15 × Global中位数`。
- RT-at-DA：稳健XGBoost（伪Huber）。
- 滚动RT：稳健XGBoost（绝对误差）。
- 偏差罚金、退化成本和连续DA-LP/RT-MPC合同保持不变。

## 运行流程

1. 只根据2023内部训练记录冻结seed 0/1/2的最终轮次为10/5/19，并逐轮复用相应的学习率轨迹。2024不参与早停、学习率调度或checkpoint选择，只在最终轮次评估一次。
2. 使用2020—2023重训三任务稳健XGBoost，损失类型不变。
3. 在2024导出三个Global DA预测并逐小时取中位数。
4. 应用冻结`-15%`公式；不在2024搜索新权重。
5. 在同一连续DA-LP、锁定DA计划、滚动RT-MPC和完整双结算下比较。

## 2024结果

- 冻结候选：86.49 美元/节点·日。
- 稳健XGBoost：90.69 美元/节点·日。
- 候选/基线日收益中位数：25.82 / 29.15。
- 候选/基线最高10天收益占比：39.16% / 39.46%。
- 配对差值：-4.20 美元/节点·日。
- 7日块bootstrap 95%区间：[-8.01, -1.23]。
- 结论：没有超过稳健XGBoost基线；不能进入2025。

### 收益拆分

- 候选DA收入项：`125.11`；基线：`131.60`。
- 候选RT偏差结算项：`-0.08`；基线：`+0.07`。
- 候选退化成本：`28.37`；基线：`30.46`。
- 候选偏差罚金：`10.17`；基线：`10.52`。
- 候选虽然少付约`2.45`的退化与偏差成本，但DA收入少约`6.49`，所以净收益仍低`4.20`。
- 15个节点的候选年均收益都为正，正收益日比例为`77.69%`；问题不是系统整体亏损，
  而是没有达到更强的XGBoost机会收益。
