# 其余模型复刻审计

## 1. 本轮原则

奥地利只用于冻结外部测试，禁止使用奥地利标签进行训练、微调、选模或参数选择。只实现老师榜单中可以由聊天、交接文档、冻结模型或完全确定的规则还原的方法；同类代理必须显式标为`proxy`，不得冒充老师checkpoint。

## 2. 规则基线核验

`d-1 persist`按原生15分钟序列严格向后移动96点，得到总MAE `26.081`，与老师的`26.095`只差`-0.014`，证明本地真值、时间轴、分组和评分代码基本对齐。

常见的周季节朴素规则（向后移动672个15分钟点）得到总MAE `29.659`，与老师`SeasonalNaive = 58.046`相差`-28.387`。因此老师的SeasonalNaive不是这条常见规则，或使用了不同覆盖区间/实现；本轮只保存为候选规则检查，不登记为老师模型复现。

## 3. 其余模型可复刻性

| 老师模型 | 已知信息 | 当前结论 |
| --- | --- | --- |
| TimesFM3-ZS-mainU11 | 11路特征清单、冻结模型 | 已完成6路同类代理近似，MAE 18.841，见文档8 |
| Chronos2-ZS-fat8192 | 16路future与12路past特征族、冻结模型 | 已完成14+3路代理近似，MAE 18.803，见文档9 |
| d-1 persist | 规则明确 | 已近乎精确复现，MAE 26.081 |
| LGBM32-WF | 32维清单、约2年窗口、每周重训 | 本地缺少训练期的日前功率、分电源实发、天气预报和TTF历史；且禁止用奥地利标签重新训练 |
| BRIM | 论文给出168小时价格+未来24小时EXAA、BiLSTM | 本地没有EXAA和老师权重；不能复刻 |
| TimesFM3-LoRA-tempB | 仅有名称和汇总MAE | 缺LoRA权重、温度/采样策略和训练配置 |
| PGRRN-v3 | 论文可确认门控稀缺性残差结构 | 缺老师版本特征、超参数和权重，不能复刻v3 |
| LEARX-daily | 交接只说明应使用较小辅助特征集 | 缺精确特征清单、正则化、滚动窗与冻结预测 |
| Loizidis-ELM+PNN | 论文可确认PNN正负分类与ELM-bootstrap组合 | 缺老师训练配置、bootstrap设置和权重 |
| TFT-Quantile | 只有名称和汇总MAE | 缺特征、窗口、分位数损失配置和权重 |
| Ni-spike-calib | 论文可确认EVT/GEV与事后尖峰校准思路 | 缺老师校准参数、覆盖日与逐时预测 |
| Naive-d1 | 只有名称、n=358和汇总MAE | 与d-1 persist的具体差异未说明，不能靠猜测补齐 |
| DLinear / DLinear-full | 只有名称、覆盖数和汇总MAE | 老师未提供训练市场、窗口、输入、权重及`full`定义；禁止自行用奥地利重新训练 |
| SeasonalNaive | 只有名称、n=358和汇总MAE | 常见lag-7d规则与榜单严重不符，不能认作复现 |
