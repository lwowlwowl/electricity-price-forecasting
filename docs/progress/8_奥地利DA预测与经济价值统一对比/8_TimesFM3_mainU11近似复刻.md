# TimesFM3 mainU11近似复刻

## 任务边界

本轮只复刻老师给出的`TimesFM3-ZS-mainU11`思路，不加入日历增强、EXAA、校准、融合、路由或decision-aware组件。奥地利数据不参与训练、微调、特征筛选或参数选择，TimesFM3权重全程冻结。

老师的原方法使用11路`past_future`协变量。当前仓库没有对应的日前预测、跨境容量和TTF原始序列，因此本轮不是精确复现，而是保留能从现有数据对应出的同类信息，命名为`TimesFM3-ZS-mainU11-proxy6`，避免与老师结果混淆。

## 特征对应

| 老师特征 | 本轮对应 | 处理方式 |
| --- | --- | --- |
| `at_gen_da_a71` | `at_gen_da_a71_proxy` | 使用预测日前7天同一时刻的系统负荷，作为同量纲系统平衡代理 |
| `at_resload_da` | `at_resload_da_proxy` | 预测日前7天同一时刻的负荷减风电、光伏 |
| `at_solar_da` | `at_solar_da_proxy` | 预测日前7天同一时刻的光伏实发 |
| `at_wind_da` | `at_wind_da_proxy` | 预测日前7天同一时刻的风电实发 |
| `wx_sw_rad` | `wx_sw_rad_proxy` | 预测日前7天同一时刻的短波辐射观测 |
| `wx_wind10_ms` | `wx_wind10_ms_proxy` | 预测日前7天同一时刻的10米风速观测 |
| 四路`maxbex_*` | 缺失 | 不伪造、不补入其他变量 |
| `ttf` | 缺失 | 不伪造、不补入其他变量 |

所有未来窗口代理都来自整整7天前，预测日当天的实测值不会进入输入。没有添加老师清单以外的特征。

## 评价协议

- 模型：官方冻结`TimesFM3 3.0`；
- 上下文：过去4,096个15分钟点；
- 预测：一次输出未来96个15分钟价格；
- 区间：2025-10-01至2026-09-30，共365个奥地利本地交易日、35,040点；
- 分组：沿用老师的负价日、尖峰日和普通日定义，尖峰阈值为`212.4560 EUR/MWh`；
- 老师榜单为366天，因此以下差值用于工程接近度判断，不是完全同协议的复现误差。

## MAE结果

| 日组 | 本轮proxy6 | 老师mainU11 | 差值（本轮－老师） | 相对差距 |
| --- | ---: | ---: | ---: | ---: |
| 全部 | 18.841 | 16.532 | +2.309 | +13.97% |
| 负价日 | 22.888 | 20.052 | +2.836 | +14.14% |
| 尖峰日 | 24.873 | 21.065 | +3.808 | +18.08% |
| 普通日 | 13.944 | 12.714 | +1.230 | +9.67% |

本轮总MAE比老师结果高`2.309 EUR/MWh`。普通日最接近，尖峰日差距最大，这与缺少跨境容量、TTF以及真正日前风光/负荷预测信息相符：这些变量在极端价格期间的解释力通常更重要。该解释是基于缺失变量与分组差距的合理推断，不是消融实验的因果结论。

## 数据与评分口径校验

老师榜单中的`d-1 persist`定义明确，因此另外按“原生15分钟序列向后移动96点”重算：

| 日组 | 本地重算 | 老师榜单 | 差值（本地－老师） |
| --- | ---: | ---: | ---: |
| 全部 | 26.081 | 26.095 | -0.014 |
| 负价日 | 30.176 | 30.148 | +0.028 |
| 尖峰日 | 33.673 | 33.488 | +0.185 |
| 普通日 | 20.248 | 20.423 | -0.175 |

总体只差`0.014 EUR/MWh`，说明本地DA真值、15分钟时间对齐、日分组和MAE计算与老师榜单基本一致。由此看，TimesFM3的`2.309`差距主要不能归咎于评分代码；更直接的差别是协变量只有6路代理而非老师的11路原始日前特征，以及本地少一个普通日。
