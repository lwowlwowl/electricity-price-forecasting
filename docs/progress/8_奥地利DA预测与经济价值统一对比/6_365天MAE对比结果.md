# 365天奥地利DA分组MAE结果

> 性质：冻结模型DA-only外部评价。奥地利数据不参与训练、微调、归一化拟合、seed选择、路由阈值选择或融合权重选择。

## 材料来源

老师的精确MAE榜单和TimesFM3、Chronos2特征清单，原始来源是微信聊天记录，已经归档 `attachments/teacher_chat_1.png`、`teacher_chat_2.png`和`teacher_chat_3.png`。仓库中的 `1_老师要求与基线材料.md`是对聊天记录的首次文字归档。

`2_AT_DA_PRICE_FORECAST_TEAM_HANDOFF.md`是组员提供的特征工程交接文档，主要说明数据源、门控前可知规则、 LightGBM 32维特征及基础模型差异；它不是下面这份完整MAE榜单的原始出处。本文件把聊天榜单、聊天中的精确特征说明和本仓库新计算结果合并在一起，作为单一阅读入口。

## 评价口径

- 区间：2025-10-01至2026-09-30，共365个奥地利本地交易日；
- 分辨率：原生15分钟，共35,040个时段；
- 夏令时：保留本地日原生92/96/100点；
- MAE：将相应日组内所有15分钟绝对误差汇总后取平均；
- 日分组：任一价格小于0为负价日；否则日最高价不低于`212.4560 EUR/MWh`为尖峰日；其余为普通日；
- 分组计数：负价日63、尖峰日112、普通日190。

原始文件的2026年9月DA真值完整，但RT列为空。由于冻结DA Transformer把过去168小时RT价格作为输入，本轮从APCS官方`Statistik-RZ September 2026`补入2,880个历史RT点，仅用于模型因果输入，不运行收益结算，也不修改冻结Parquet。使用2026年8月2,976个重叠点核验字段口径，最大绝对差为`0.00558 EUR/MWh`，对应原文件的两位小数舍入。

## 老师聊天中的特征说明

### TimesFM3（main∪11 / ZS与LoRA）

TimesFM3使用11路`past_future`协变量，没有`past_only`：

1. `at_gen_da_a71`
2. `at_resload_da`
3. `at_solar_da`
4. `at_wind_da`
5. `maxbex_at_de`
6. `maxbex_at_hu`
7. `maxbex_cz_at`
8. `maxbex_de_at`
9. `ttf`
10. `wx_sw_rad`
11. `wx_wind10_ms`

目标序列为价格`y`，显式日历变量没有进入这11路。原榜单版本没有EXAA；老师后续完成的`TimesFM3-ZS-mainU11+EXAA`在`at_da_features`中增加小时级`exaa`，并把它作为第12路`past_future`协变量，小时值重复到4个15分钟点。该版本全部MAE为`12.603`，相对无EXAA版本的`16.532`降低约`23.77%`。

### Chronos2（ZS fat8192）

Chronos2默认`fat`集合由16路`past_future`和12路`past_only`组成。

`past_future`在门控时可知，同时进入历史上下文与未来区间：

- 日历：`hour_sin/cos`、`dow`、`is_weekend`、`month_sin/cos`、`is_holiday`；
- 日前功率：`at_load_da`、`at_solar_da`、`at_resload_da`、`at_gen_da_a71`；
- 天气与燃料：`wx_temp_c`、`wx_wind10_ms`、`wx_sw_rad`、`wx_cloud_pct`、`ttf`。

`past_only`只进入历史区间，是12路`gen_*_lag24`实发类变量：抽蓄、跨境、径流、生物质、地热、水库、其他、垃圾、光伏实发、残载、可再生占比和抽蓄净额等。

### 两套基础模型特征差异

| 特征类别 | TimesFM3 main∪11 | Chronos2 fat |
| --- | --- | --- |
| 日历 | 无 | 有 |
| MaxBex | 有4条 | 无 |
| 负荷DA | 使用`resload`，无`at_load_da` | 同时使用`at_load_da`和`resload` |
| 风电DA | 有`at_wind_da` | 无风电DA，但有气象风速 |
| 实发lag | 无 | 有12路 |
| EXAA | 原mainU11版本无；后续`mainU11+EXAA`版本有 | 无 |

两套特征都从`at_da_features_v1`中选择，但TimesFM3的`main∪11`来自协变量筛选，Chronos2的`fat`是脚本默认集合，不是同一轮筛选结果，不能把两套特征差异解释成严格的模型消融。
