# 365天奥地利完整双结算结果

> 完成日期：2026-11-05  
> 性质：冻结模型、零样本外部评价。奥地利数据只用于最终测试，不参与训练、微调、归一化拟合、seed选择、路由阈值选择或融合权重选择。

## 1. 先说明“小时模型”和“15分钟结算”

本次比较的两套系统都是由**小时级预测模型**构成，并不是在奥地利15分钟数据上重新训练的模型。

- `decision-aware v4最终2:1融合`：DA、RT-at-DA和rolling RT三条价格腿均来自冻结的decision-aware小时模型；每条腿使用`2/3 × seed 0 + 1/3 × 稳健三seed校准结果`。
- `三特征尾部专家Router`：DA和RT-at-DA按每天的三个尾部特征，在冻结的原Transformer三seed集成与DLinear之间选择；rolling RT使用冻结的原Transformer三seed等权结果。三个特征分别是Transformer预测价差的最大值、Transformer预测价差的10%分位数，以及DLinear预测价差为负的小时数。固定决策树以`0.70`概率阈值选择专家；该树由美国市场2023—2024记录冻结得到，没看奥地利标签。Router本身不重新预测价格，只负责选择已冻结的小时专家。

模型和结算的时间分辨率不同，接口如下：

1. 每个本地交付日，DA与RT-at-DA模型各输出24个小时价格；第`h`小时的预测复制给该小时内的4个原生15分钟交付段。
2. rolling RT模型每个整点重新起报，一次输出未来4小时；每个小时预测同样复制成4个15分钟值。
3. 虽然价格预测在同一小时的4个时段内相同，电池控制器仍然**每15分钟重新求解一次MPC**。每次只执行当前第一个15分钟动作，下一时段再根据新SOC、当日已放电量和剩余预测重新优化。
4. 这不是把小时收益简单乘4。功率约束按`Δt=0.25 h`换算，充放电量、SOC演化、DA承诺、RT偏差、退化成本和现金收入全部逐15分钟计算。
5. 夏令时不强行变成96点：正常日96点，春季前拨日92点，秋季回拨日100点。回拨时，DA与RT-at-DA的两个同名本地小时使用同一个小时标签预测，但各自作为不同的真实15分钟交付段独立结算；rolling RT沿UTC连续时间线分别起报，因此两个重复小时仍有不同的滚动预测。前拨时不存在的4个时段不人为补点。

因此，准确表述是：**冻结小时价格模型经确定性映射接入原生15分钟电池LP/MPC与双结算**。

## 2. 评价区间与共同条件

- 区间：2025-10-01至2026-09-30，共365个奥地利本地交易日；
- 原生时段：35,040个15分钟点；
- 日分组：负价日63、尖峰日112、普通日190；
- 货币与报告单位：`EUR/奥地利竞价区·日`，不是`USD/节点·日`；
- 两套系统使用完全相同的真实DA/RT价格、电池参数、优化器和结算公式；
- 两套系统分别使用自己的DA、RT-at-DA和rolling RT预测，不混用预测腿；
- 2026年9月缺失的历史RT输入由APCS官方`Statistik-RZ September 2026`补齐；原始冻结Parquet未被修改；
- 2026-10-01的DA公开价格只为9月30日最后3个rolling RT起报提供已知未来DA边界，不作为第366天评价样本。

## 3. 电池与优化协议

统一电池参数如下：

| 参数 | 数值 |
| --- | ---: |
| 功率上限 | 1 MW |
| 能量容量 | 4 MWh |
| 单程充/放电效率 | 0.95 |
| 初始SOC | 2.0 MWh |
| SOC范围 | 0.4—3.6 MWh |
| 每日本体放电上限 | 4 MWh |
| 退化成本 | 5.2661 EUR/MWh吞吐量 |
| 偏差免罚区 | DA承诺绝对值的3% |
| 超额偏差罚金 | `2 × |RT价格| × 超额偏差量` |

每天先根据预测DA与预测RT-at-DA求解日前LP，得到每个15分钟时段的净日前承诺

$$
x_t^{DA}=d_t^{DA}-c_t^{DA}.
$$
实际运行时，rolling RT MPC给出当前时段净实际动作

$$
x_t^{act}=d_t^{act}-c_t^{act},
$$
并满足功率、SOC、效率和每日放电上限。当前时段相对日前承诺的偏差为

$$
\Delta x_t=x_t^{act}-x_t^{DA}.
$$
每个15分钟时段的现金收益按双结算计算：

$$
r_t=p_t^{DA}x_t^{DA}
    +p_t^{RT}\Delta x_t
    -\kappa(c_t^{act}+d_t^{act})
    -2|p_t^{RT}|\max\!\left(|\Delta x_t|-0.03|x_t^{DA}|,0\right).
$$
其中第一项为日前市场收入，第二项为实时偏差收入，第三项为电池吞吐退化成本，第四项为超过3%免罚区后的偏差罚金。日收益是当天所有原生15分钟`r_t`之和。

### 为什么从335天的96.04降到365天的84.51

前335天的既有结算没有变化：decision-aware仍为`96.04 EUR/日`，Router仍为`-49.36 EUR/日`。新增的2026年9月30天全部属于尾部日，其中4天为负价日、26天为尖峰日，没有普通日。

| 系统 | 前335天 | 新增9月30天 | 合并365天 |
| --- | ---: | ---: | ---: |
| decision-aware | 96.04 | -44.29 | 84.51 |
| Router | -49.36 | -563.17 | -91.59 |

decision-aware在9月仍有`23/30`个正收益日，中位数为`331.17 EUR/日`；但9月14日至17日出现数个很大的偏差罚金，单日最低收益为`-3,066.67 EUR`，使该月算术平均数变为负值。因此，全年均值下降不是旧335天被改算或模型被重新训练。Router在新增9月的平均亏损更大，所以两套系统的差距反而从前335天的`145.40`扩大到365天的`176.10 EUR/日`。

#### 9月价格本身的尾部程度

9月没有夏令时切换，共30日、2,880个原生15分钟点，时间轴完整。其价格分布为：

- DA价格范围为`-7.45—632.64 EUR/MWh`，有11个15分钟点高于`500 EUR/MWh`；
- RT不平衡价格范围为`-1,125.77—2,900.00 EUR/MWh`；
- 有54个15分钟点满足`|RT价格| > 500 EUR/MWh`，其中12个超过`1,000 EUR/MWh`；
- 按冻结日分类规则，30天中有**4个负价日、26个尖峰日、0个普通日**。

本轮补入的9月RT来自APCS官方`Statistik-RZ September 2026`的`Ausgleichsenergiepreis (=Preis für Abweichung)`字段。相同字段在2026年8月与仓库原始冻结数据有2,976个重叠点，最大绝对差仅`0.00558 EUR/MWh`，差异来自小数位舍入。因此目前没有发现时区、频率、币种或RT字段选错的证据。

#### 极端结果的直接原因

问题不是单一模型失效，而是“尾部RT价格、DA与rolling RT动作不一致、额外偏差罚金”三者相乘：

1. 当前现金流已经用RT不平衡价格结算实际动作相对DA承诺的偏差；在此之外，又对超过`3% × |DA承诺|`的部分附加`2 × |RT价格|`罚金。
2. 当DA承诺接近0时，3%免罚区也接近0，rolling RT只要进行小幅调整就几乎全部进入罚金项。
3. DA计划与rolling RT由分别训练的预测腿驱动；9月价格结构变化使两者更容易给出不一致动作。即使RT价格只是持续处于约`200—400 EUR/MWh`，一整天多个时段的偏差累加后也可形成数千欧元罚金。因此最大亏损日不一定恰好等于RT单点最高价日。
4. 这项额外罚金对11套系统平均扣除`325.74—961.14 EUR/日`，是所有系统9月转负的直接现金原因。按原动作加回该项后，11套系统中9套为正收益。

因此应区分两个结论：**数据层面**暂未发现明显错误，9月确实是尾部月份；**方法层面**，`2 × |RT价格|`额外罚金是本项目沿用的压力测试假设，目前尚未证明它等同于奥地利实际不平衡结算规则。正式对外解释时，应把“含额外偏差压力测试”的当前结果与“严格按奥地利官方结算规则”的结果分开；在核实奥地利规则前，不能把9月巨亏全部解释成模型经济价值突然失效。

## 6. 收益来源与稳健性

| 日均现金组成 | decision-aware | Router |
| --- | ---: | ---: |
| DA收入 | 233.20 | 128.35 |
| RT偏差收入 | -12.99 | -16.66 |
| 退化成本 | -27.03 | -20.10 |
| 偏差罚金 | -108.68 | -183.18 |
| 最终净收益 | **84.51** | **-91.59** |

decision-aware的主要优势是更高的DA收入，并将日均偏差罚金从`183.18`降到`108.68 EUR`。它的吞吐量更大，所以退化成本也更高；因此结果不能解释为“少做动作自然少亏”，而是更有价值且与RT偏差更协调的日前承诺与实时调整。

配对稳健性结果：

- 日收益差的7日块bootstrap 95%区间为`[81.73, 275.21] EUR/日`，区间完全高于0；
- 删除decision-aware相对Router优势最大的5天后，平均增益仍为`133.20 EUR/日`；
- 各自删除收益最高的5天后，decision-aware仍为`68.46 EUR/日`，Router为`-106.12 EUR/日`；
- 两套系统全年SOC违规均为0。

因此，当前证据支持“decision-aware在这套冻结零样本结算协议下稳定优于Router”，而不是由少数极端日偶然抬高均值。

## 7. 与MAE结果如何一起解释

同一365日上，decision-aware的DA MAE为`25.6870 EUR/MWh`，Router为`27.1867 EUR/MWh`，前者在负价、尖峰和普通日三个子集也都更低。结算中前者又高出`176.10 EUR/日`，所以这次外部测试同时观察到更低MAE和更高经济价值。

但decision-aware的MAE仍未超过老师榜单中的BRIM、TimesFM3、Chronos2和LGBM32。老师目前只提供了这些模型的汇总MAE，没有逐15分钟预测或DA、RT-at-DA、rolling RT三条预测腿，因此**现在不能替这些模型运行同一储能结算，也不能声称decision-aware的收益已经超过它们**。若要做公平经济对比，需要对方提供至少与本协议同区间的三条逐时/逐15分钟预测及其起报时间。
