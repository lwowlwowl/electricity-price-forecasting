## 1. 阶段划分

### 1.1 第二阶段：多节点无ID通用系统与论文基线闭环

第二阶段已经完成以下工作：

1. 建立DA、RT-at-DA和rolling RT三个互不共享参数的无ID Transformer价格模型；
2. 完成四折留一市场零样本迁移、ERCOT多seed和当前协议结构消融；
3. 完成lag-168、pooled/逐节点XGBoost、TimesFM-3、TimesFM-2.5 LoRA、DLinear和LEAR比较；
4. 完成负价、尖峰、极端价差、跨年DA失稳及收益分解诊断；
5. 完成四市场2020—2024最终训练和一次性2025锁定评价；
6. 完成ERCOT连续DA LP、rolling RT MPC、偏差罚金、退化成本、风险统计和产物哈希审计。

第二阶段最终结论保持不变：Transformer在六个覆盖完整三任务的基线比较中取得12/12项MAE优势，
但ERCOT 2025日均净收益为`28.04 USD/节点·日`，低于公平pooled XGBoost的`44.43`；配对差为
`-16.39`，7日块95%区间为`[-23.19, -10.05]`。因此第二阶段只能主张统一预测优势，不能主张
经济收益优于XGBoost。

第二阶段不再追加模型、seed、结构或基线。详细结果见`54_2025一次性锁定测试最终结论.md`；原实验
清单`47_论文待补实验TODO.md`保留为封存证据，不再是活跃任务入口。

## 2. 为什么保留旧TODO和过程文档

旧TODO、云端交接和失败实验文档不删除，原因不是它们仍待执行，而是它们记录了：

- 数据、信息截止时刻和结算合同如何形成；
- 哪些实验已经运行、失败或被停止；
- 预注册、结果哈希和主张边界；
- 为什么不能重新启动带ID经济状态头、端到端零阶训练或结构笛卡尔积。

删除这些小型文本文件几乎不节省空间，反而会破坏论文数字和实验决策的可追溯性。它们统一视为
**只读历史证据**；当前阅读入口只保留本文件、`55`、`54`和`00`号索引。

## 3. 第三阶段：针对电价尾部的独立研究

老师提出的核心问题是：现有价格模型虽然平均误差较低，但会把负价、尖峰价和极端DA—RT价差压平，
从而使DA计划收益不足。第三阶段不重新讨论端到端训练，研究重点是解释并修复尾部动态。

### 3.1 固定对照与候选

| 角色 | 系统 | 用途 |
|---|---|---|
| 对照基线 | 第二阶段原始Transformer | 衡量不做尾部处理时的预测、动作与盈利 |
| 简单候选A | DA上下1%价格样本总权重2 | 检验仅改变训练样本重要性是否足以改善尾部与DA价值 |
| 条件候选B | 尚未冻结 | 只有A不能解释或修复尾部时，才允许另行预注册一个事件条件/概率适配机制 |

原始Transformer始终是尾部阶段的主对照，不能把尾部加权改称“基线”。尾部加权是已完成2023开发、
2024冻结确认的单因素候选，其公式、结果和云端入口见
`55_DA尾部加权跨年确认与2025跟进预注册.md`。

### 3.2 当前唯一已授权的计算

- [ ] 按冻结配置训练四市场2020—2024尾部加权DA的seed 0/1/2；
- [ ] 固定三seed等权集成，只进行一次2025跟进评价；
- [ ] 复用原RT-at-DA、rolling RT、全部外部基线和同一LP/MPC结算合同；
- [ ] 同时报告DA计划收益、RT修正、偏差罚金、退化成本和最终净收益；
- [ ] 报告负价召回、正向尖峰召回、尾部幅度、极端价差方向/幅度以及普通时段MAE；
- [ ] 无论结果好坏均归档，不根据候选2025结果修改阈值、权重、结构或seed。

盈利仍是主终点。MAE和尾部指标只回答“为什么盈利变化”，不得用平均MAE覆盖净收益结论。

### 3.3 老师要求对应的研究问题

第三阶段至少要明确回答：

1. 原始模型把哪些尾部事件压平：负价、正向尖峰还是极端DA—RT价差；
2. 尾部加权改善的是事件召回、幅度、时点排序，还是只改变了少数动作；
3. DA计划收益改善是否伴随普通时段误差、偏差罚金或退化成本恶化；
4. 简单加权若仍无法召回正向尖峰，下一种机制为什么能比普通加权更有针对性；
5. 所有预测变化如何通过同一LP/MPC合同传递到最终净收益。

## 4. 第三阶段边界与停止规则

1. 原2025结果已经观察，第三阶段2025结果必须称为`post-original-test follow-up`，不能包装为首次盲测；
2. 候选A不得做权重或分位数网格搜索；上下1%、总权重2已经冻结；
3. 候选B若要启动，必须先写独立预注册，并且一次只改变一个机制；
4. 不在本阶段加入端到端利润反传、新MPC、市场专属阈值或最佳seed选择；
5. 若A没有稳定改善，先报告负结果和机制诊断，不以继续调参替代结论；
6. 真正新的未污染时间外确认需要2026或更新年份，不能由已经观察过的2025承担。
