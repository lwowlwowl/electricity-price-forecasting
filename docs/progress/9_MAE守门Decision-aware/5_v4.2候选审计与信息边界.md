# v4.2候选审计与信息边界

## 目标与结论

本轮要求纯v4在不使用EXAA、外部模型价格预测或其他欧洲训练集的前提下，
同时满足：奥地利DA MAE不高于`16.630 EUR/MWh`、平均收益不低于
`84.509256 EUR/日`、SOC违规为0。该目标**尚未完成，因此没有冻结或命名
v4.2**。

当前最强合规候选是逐小时情景记忆（hour-level MemCast）加决策等价投影：

| 指标 | 结果 |
|---|---:|
| 投影前DA MAE | 20.6563 EUR/MWh |
| 投影后DA MAE | 21.7408 EUR/MWh |
| 平均净收益 | 84.509256 EUR/日 |
| 最大逐日收益差（相对冻结v4） | 2.79e-12 EUR |
| SOC违规 | 0 |

它比上一版投影后纯v4的`21.9423`改善`0.2015 EUR/MWh`，但距离前五门槛
仍差`5.1108 EUR/MWh`，只能作为候选分支，不能宣称v4.2已经得到。

## 2026方法复核

| 路线 | 合规口径 | 奥地利投影前MAE | 结论 |
|---|---|---:|---|
| COSA式源先验线性残差头 | 因果在线适配，非静态零样本 | 21.4699 | 失败 |
| 延迟安全RLS专家库 | 因果在线适配，非静态零样本 | 21.4475 | 失败 |
| 美国源域状态门控残差树 | 严格外部泛化 | 22.0998 | 失败 |
| 整日MemCast情景记忆 | 因果历史输入、无目标拟合 | 20.7878 | 小幅有效 |
| 逐小时MemCast情景记忆 | 因果历史输入、无目标拟合 | **20.6563** | 当前最佳候选 |
| 每周因果树TTA | 因果在线适配，非静态零样本 | 21.0524 | 失败 |
| 四个早期decision-aware checkpoint | 严格外部泛化 | 26.8908--27.4138 | 失败 |

逐小时MemCast的规则完全由美国源市场选择：使用112日记忆、7个邻居，
冻结v4价格曲线/物理状态/日历距离权重为`1/2/0.5`，对相似历史小时残差
取中位数，并以`0.75`门控。ERCOT留一标准化MAE从`1.3192`降至
`1.1479`；奥地利推理只检索预测时已经公布的历史价格，不拟合奥地利参数。
每个预测点均可回溯其参考日期、物理距离、置信度和修正量。

方法依据：

- [MemCast, ICML 2026](https://proceedings.mlr.press/v306/tao26a.html)：经验记忆与动态置信度；
- [MetaGrid, 2026](https://arxiv.org/abs/2610.17387)：跨市场元训练与共享物理规律；
- [Market-information-aware Gated-LoRA, 2026](https://arxiv.org/abs/2608.11359)：用供需状态控制源域适配器；
- [COSA, ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/2a8ce71baac4c89bf9ff479d8240c7d9-Abstract-Conference.html)：泄漏安全的输出空间在线适配；
- [Delay-aware TTA audit, 2026](https://arxiv.org/abs/2610.12232)：必须先预测后更新，且TTA在不少数据集上会退化。

## 为什么现有信息仍不能进前五

负价日和尖峰日分别占63日和112日；当前候选在这两组的投影后MAE仍为
`27.5916`和`27.4333`，普通日已经降至`16.4452`。瓶颈不是一般日拟合，
而是交付前无法识别奥地利特有的极端价格制度。仓库现有纯v4输入只有历史价格、
负荷、风电、光伏、天气和日历，缺少榜单强模型使用的跨境容量、TTF天然气和
邻近早盘价格。继续只调网络、融合权重或在线校准，无法恢复没有观测到的信息。

若坚持严格纯v4外部泛化，下一步应先在四个美国市场构建与奥地利可对应的
跨区交换/燃料紧张度变量，再重新做留一市场训练；若允许奥地利特有公开信息，
现有`v4+EXAA`已经达到`14.5417`，但它必须作为另一条信息增强路线报告，不能
伪装成纯v4。
