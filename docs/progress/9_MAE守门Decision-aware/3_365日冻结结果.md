# 奥地利365日冻结结果

## 评价协议

- 区间：2025-10-01至2026-09-30，共365个奥地利本地交易日；
- 分辨率：原生15分钟，保留夏令时日的92/100点；
- 迁移：严格零样本，奥地利DA标签不参与训练、调参或结构选择；
- MAE：全部35040个15分钟点的点加权MAE；
- 收益：与冻结v4相同的RT-at-DA、rolling RT、电池和LP/MPC结算协议。

## 审计结论

- 没有读取、融合或蒸馏TimesFM3+EXAA预测；
- 预测生成过程不读取奥地利DA真值；
- 最大KKT驻点残差为$1.99\times10^{-13}$；
- 冻结v4计划在新目标下的最大最优值差为$4.55\times10^{-13}$；
- 显式词典序次问题与冻结v4解的最大变量差不高于$10^{-7}$；
- 收益守门、MAE守门和SOC守门均通过。
