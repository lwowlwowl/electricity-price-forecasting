三个模型都从随机初始化开始，无lag168、无XGBoost输入/残差/教师信号。按逐2023
节点等权macro MAE保留两个候选：

- DA + MAE：epoch 2/5 = `36.90 / 37.70`；
- RT-at-DA + 伪Huber：epoch 10/12 = `41.18 / 55.33`；

稳健XGBoost对应MAE为DA `35.57`、RT-at-DA `35.30`、滚动RT第一步 `23.00`。
新自有模型已大幅改善旧Global，但三个任务仍都未超过XGBoost，其中RT-at-DA差距最大。

## 3. 27个新/旧自有模型组合

组合池只包含两档新候选和一档旧稳定Global，不包含XGBoost混合。最佳组合为：

- 新DA epoch 5；
- 旧稳定RT-at-DA epoch 4；
- 新滚动RT epoch 5。

其结果：

- 收益：`241.70`；
- 相对旧稳定Global：`+51.00`，95%区间`[18.80, 95.49]`；
- 相对XGBoost：`-50.59`，95%区间`[-81.73, -24.57]`；
- 最大回撤：`145.93`，优于XGBoost的`206.07`；
- 去掉最好5日后收益：`167.17`，XGBoost为`210.51`。

三个单任务替换对旧Global的贡献：

- 新DA：`+38.96`，95%区间`[9.78, 82.47]`，稳定正贡献；
- 新RT-at-DA：`+38.63`，95%区间`[-27.46, 105.14]`，不稳定；
- 新滚动RT：`+13.70`，95%区间`[5.41, 28.03]`，稳定正贡献。

这证明任务专属损失方向是有效的，但RT-at-DA的价差方向和尖峰幅度仍是主要瓶颈。

## 4. 关键事件加权消融

按第35—37号文档预先冻结的顺序，因任务专属损失仍未超过XGBoost，现只启动一条
严格消融：保持架构、融合、损失类型和优化参数不变，仅开启训练期关键事件加权。

该路线：

- 只用2020—2022每节点分位数拟合阈值；
- 对价格上/下尾、大DA−RT价差和价差符号反转有限增权；
- 滚动RT额外强调MPC真正执行的第一步；
- 权重上限为3，不使用ERCOT固定美元阈值，因此可迁移到其他市场；
- 不读取2024/2025，不使用XGBoost教师或输入。

AutoDL预检已确认固定环境、RTX 4090D和源数据SHA256不变。正式流水线已于
2026-10-10 18:22（Asia/Shanghai）启动，预计约80—100分钟。
