# 负价事件适配器

> 日期：2026-10-20  
> 状态：**本轮已完成；NEG-E保留为后续候选，NEG-A否决；未读取2025。**

## 1. 实验结论

第一版“每市场、每类别等权”的稀疏逻辑事件头在源市场验证阶段被否决：NYISO/PJM训练期分别只有19/10个负价小时，等权会把这些极少样本过度放大。阈值0.95时源市场宏平均假阳性率仍约15.2%，不进入盈利评价。该失败结果保留在`data/results/negative_price_adapter_v1/`，不能删除或包装成有效模型。

第二版按运行前冻结协议，只使用具有明确解释的周季节价格、近期负价环境和日历特征，并以三个源市场非负小时99%分位数中的最大值冻结阈值`0.825630`。模型只在CAISO/NYISO/PJM 2020—2022训练，阈值只由三市场2023确定；ERCOT 2023/2024均不参与拟合和选模。

NEG-A虽然继续降低负价MAE，却没有增加净收益：相对NEG-E少约`0.01 USD/节点·日`，并带来更多退化成本及更弱的RT修正腿。因此**保留事件头NEG-E，否决条件幅度头NEG-A**。这也再次证明本项目的选择标准是完整盈利，不是单独的尾部MAE。

## 3. 可解释性

NEG-E绝对值最大的标准化系数为：

| 特征 | 系数 | 解释 |
|---|---:|---|
| 168小时前同小时DA价 | -2.664 | 上周同小时价格越低，本周负价概率越高 |
| 小时余弦 | -1.342 | 负价有明显日内时段规律 |
| 月份正弦 | +0.755 | 负价有季节性 |
| 周末 | +0.693 | 低负荷周末更容易出现供给过剩 |
| 168小时历史负价占比 | +0.358 | 近期负价环境具有持续性 |

模型没有读取节点或市场身份，推理只需起报时已经可见的历史量和目标日历。它不是端到端利润模型，也没有修改LP/MPC。

## 4. 论文表述与停止决定

允许写：一个受源市场误报约束的可解释事件适配器，在未见ERCOT标签的情况下改善了负价召回与负价MAE，并在2023/2024都产生正的点估计收益增量；但区间跨0，经济改进尚不稳定。

禁止写：NEG-E显著提高盈利、NEG-A有效、或本轮已经解决DA计划收益不足。

本轮线性适配停止，不继续调阈值、加特征或扩大回归器。NEG-E只作为负价事件基线保留；
后续局部价格动态实验及其多seed否决结论见本阶段第3份文档。
