# PRD：多市场电价预测与储能双结算系统

> 版本：v2.0（2026-10-19）
> 状态：实验主线已闭环；本文档只保留现行需求、最终协议和主张边界。
> 历史试验、失败路线与逐次执行日志见`docs/progress/`，不再重复写入本PRD。

## 1. 项目目标

本项目研究两个相互关联、但必须分别检验的问题：

1. 能否用同一套无节点/市场身份输入的模型，在CAISO、ERCOT、NYISO和PJM上完成日前（DA）与
   实时（RT）价格预测，并迁移到训练中未见的市场；
2. 这些预测能否在严格的信息截止时点下，经可执行的日前线性规划（LP）和实时模型预测控制
   （MPC）转化为更高的储能净收益。

论文的首要业务目标是**净收益**。MAE与Pseudo-Huber只是训练价格预测器和诊断迁移能力的代理量，
不能替代同一结算合同下的盈利比较。

## 2. 最终系统边界

最终系统不是端到端利润模型，而是模块化的“价格预测 + 后置优化”：

1. DA Transformer在交付日前预测目标日24小时DA价格；
2. RT-at-DA Transformer在与DA相同的信息截止时点预测目标日24小时RT价格；
3. rolling RT Transformer在交付日每小时预测未来4小时RT价格；
4. DA LP使用前两个预测生成24小时计划；
5. RT MPC每小时使用rolling RT预测滚动修正，只执行当前第一个动作；
6. 真实DA/RT价格只在动作确定后进入双结算账本。

三个Transformer互不共享参数、优化器或checkpoint。最终利润不会反向更新Transformer；“联合”仅指
三组预测在LP/MPC决策层汇合。

## 3. 数据与信息合同

### 3.1 市场与节点

- CAISO 3节点、ERCOT 15节点、NYISO 11节点、PJM 35节点，共64节点；
- `node_id`与`market_id`仅用于采样、结果汇总、SOC隔离和审计，不输入最终神经网络；
- 训练采用市场—节点平衡采样，防止PJM因节点数量较多主导梯度。

### 3.2 输入与预测时点

- 历史窗口固定为168小时；
- 历史输入包括DA价、RT价、负荷、风电与光伏、日历；
- DA和RT-at-DA只能使用各市场冻结起报时刻已经可见的信息，以及目标日已知日历；
- rolling RT可额外读取已经公布的目标小时DA价格；
- 任何任务都不得读取未来真实价格、负荷、风电或光伏；
- 归一化只使用当前样本历史窗口的中位数与MAD，不读取目标市场全局统计量。

目标日历是起报时已经确定的8维时间信息，用来告诉解码器“正在预测目标日的哪个小时”；它不是未来
价格或负荷。各市场精确起报、时区与缓存隔离合同见`docs/progress/3_多节点Global与跨市场泛化/6_四市场起报合同与缓存隔离.md`。

## 4. 最终预测模型

### 4.1 共享骨干

- 模型宽度`d_model=128`；
- 价格、负荷、风光、系统量与日历采用独立流编码；
- 连续时间流由两层Transformer编码，时间位置使用RoPE；
- 来源融合后形成168小时Memory；
- DA/RT-at-DA使用24个目标Query，rolling RT使用4个目标Query；
- 输出经反归一化并截断到`[-500, 10000] USD/MWh`。

### 4.2 三任务冻结结构

| 任务 | 融合结构 | 训练损失 | 输出 |
|---|---|---|---|
| DA | F1来源注意力 | MAE | 次日24小时DA价格 |
| RT-at-DA | F0残差MLP | Pseudo-Huber | 次日24小时RT价格预期 |
| rolling RT | F1来源注意力 | MAE | 未来4小时RT价格 |

F0把同一小时的来源表示拼接后用残差MLP融合；F1用来源注意力学习价格、负荷、风光、系统量和日历之间
的关系。当前组合来自开发期结构筛选，并在现行无ID协议下做过受控替换检查；未发现足以更换组合的
稳定证据。

MAE为平均绝对误差。Pseudo-Huber在小误差附近平滑、对大误差近似线性，用于降低RT-at-DA尖峰对
梯度的破坏。它们都不是利润函数。

### 4.3 训练与集成

- 优化器：AdamW；初始学习率`2×10^-4`，权重衰减`0.01`；
- batch size 16，最多20个epoch，早停patience 7；
- 验证选择使用“节点MAE → 市场宏平均”，不按节点样本量加权；
- seed固定为0、1、2，不选择盈利最高的seed；
- 最终部署预测为三个seed逐点等权平均。

## 5. 决策与盈利评价

### 5.1 电池合同

| 项目 | 冻结值 |
|---|---:|
| 最大充/放功率 | 1 MW |
| 额定容量 | 4 MWh |
| SOC范围 | 0.4–3.6 MWh |
| 初始SOC | 2 MWh |
| 充/放效率 | 0.95 / 0.95 |
| 每日放电量上限 | 4 MWh |
| 吞吐退化成本 | 5.7 USD/MWh |
| 偏差容忍带 | `3% × |DA动作|` |
| 超容忍偏差罚金 | `2 × |RT价格| × 超限电量` |

`5.7/0.95=6.0 USD/MWh`只曾用于历史带ID经济状态头的近似方向阈值，不会在当前系统中重复扣费；
历史经济状态头与pre-encoder身份条件化均不属于最终无ID模型。

### 5.2 主评价顺序

1. 同一预测协议下报告MAE、偏差、负价识别、尖峰召回、DA−RT价差方向及幅度；
2. 所有完整三任务系统进入同一DA LP、RT MPC和双结算账本；
3. 主要经济终点为ERCOT节点等权日均净收益；
4. 同时报告7日块Bootstrap区间、最大回撤、最差节点、去最高5/10日和收益分解；
5. 只有收益差大于0且95%区间下界大于0，才称为稳定盈利胜出。

CAISO、NYISO和PJM尚未冻结各自完整结算合同，因此只报告预测与尾部指标，不报告推测性利润。

## 6. 比较系统与公平性

### 6.1 完整三任务基线

- lag-168周季节复制；
- DLinear简单深度模型；
- TimesFM-3 frozen；
- TimesFM-2.5源市场监督LoRA；
- pooled XGBoost：与Transformer使用相同市场和年份训练；
- 逐节点XGBoost：使用目标节点历史的监督强基线。

逐节点XGBoost不是一个模型，而是由节点、任务和预测时距专属回归器组成的系统；评价时，各节点只
调用自己的模型组，再把全部预测送入与Transformer完全相同的LP/MPC。

### 6.2 LEAR的角色

LEAR是cutoff-safe的经典稀疏线性日级预测基线。最终2025评价已完成四市场DA与RT-at-DA共8项，
但它不适用于逐小时滚动4小时RT，因此：

- 可以在DA、RT-at-DA预测表中与Transformer比较；
- 不计入“完整三任务基线”的12项全覆盖比较；
- 不把LEAR与别的rolling RT模型临时拼成未预注册的盈利系统。

## 7. 实验协议

### 7.1 零样本迁移：四折LOMO

四个市场轮流作为完全不可见的测试市场；每折只用另外三个市场的2020—2022数据训练，在2023测试。
LOMO用于证明迁移能力，不等同于最终部署训练。

### 7.2 最终部署：all-market 2025锁定测试

在不读取2025的前提下冻结结构、损失、seed、集成、基线、尾部阈值和盈利判据；随后用四市场
2020—2024数据训练，2025只评价一次。`selection_allowed=false`，最终结果不得用于回选模型。

## 8. 最终结果

### 8.1 四市场2025预测

单位为USD/MWh；粗体表示该列最低值。LEAR只覆盖两个日级任务。

| 方法 | DA MAE | RT-at-DA MAE | rolling RT MAE |
|---|---:|---:|---:|
| Transformer固定集成 | 10.46 | **15.14** | **9.69** |
| LEAR | **10.14** | 15.51 | — |
| TimesFM-3 frozen | 20.51 | 21.42 | 10.24 |
| TimesFM-2.5 LoRA | 11.72 | 16.18 | 10.98 |
| pooled XGBoost | 11.18 | 15.72 | 10.05 |
| 逐节点XGBoost | 11.03 | 15.58 | 10.03 |
| DLinear | 11.77 | 16.81 | 12.61 |
| lag-168 | 16.54 | 22.87 | 22.88 |

严谨结论是：Transformer相对六个覆盖三任务的完整基线，在四市场×三任务的12个单元全部取得更低
MAE；相对只覆盖日级任务的LEAR，Transformer在8个市场—任务单元中胜3项、LEAR胜5项。两者DA与
RT-at-DA两任务宏平均分别为`12.80`和`12.83`，总体接近，不能写成Transformer全面胜过LEAR。

### 8.2 ERCOT 2025完整盈利

单位为USD/节点·日；粗体表示对应列较优。

| 系统 | 日均净收益 | 去最高10日 | 最大回撤 |
|---|---:|---:|---:|
| Transformer固定集成 | 28.04 | 18.98 | 140.95 |
| TimesFM-3 frozen | -39.57 | -40.87 | 14,355.39 |
| TimesFM-2.5 LoRA | 35.74 | 26.37 | 198.12 |
| pooled XGBoost | 44.43 | 31.06 | 257.36 |
| 逐节点XGBoost | 59.99 | 47.08 | **129.39** |
| DLinear | **61.53** | **48.02** | 343.93 |
| 尾部专家路由（post-2025固定跟进） | **63.53** | **50.00** | 145.05 |
| lag-168 | -3.57 | -15.14 | 5,254.55 |

预注册主比较为Transformer对pooled XGBoost：收益差`-16.39`，7日块Bootstrap 95%区间
`[-23.19, -10.05]`，分类为`no_superiority`。Transformer三seed收益为`32.91/35.59/26.82`，
固定预测集成为`28.04`；不得事后选择盈利最高seed。

尾部专家路由是在原2025测试打开之后另行预注册的方法跟进，不能改写上述一次性主比较。其2025
点估计`63.53`高于所有现有系统，但相对最强静态组合的配对差区间`[-1.24, 4.75]`跨0，且绝对
正尖峰召回仍为0；论文必须同时报告这些边界，详见
`progress/6_经济协调与专家路由/2_收益优先专家路由与跨市场迁移.md`。

### 8.3 机制解释

Transformer在ERCOT三任务MAE和总体DA−RT方向准确率上略优于pooled XGBoost，但两者对最高1%极端
价差都只恢复约1.29%的真实幅度。Transformer的DA结算腿为`51.64`，低于XGBoost的`72.35`。
因此盈利落后主要是高价值小时的幅度、排序和DA计划价值不足，而不是普通时段价格全面更差。

## 9. 允许与禁止的论文表述

### 9.1 允许

- 无ID Transformer通过LOMO证明了未见市场迁移能力；
- all-market最终模型相对六个完整三任务基线具有统一预测精度优势；
- LEAR在日级任务上与Transformer接近，并在8项中胜5项；
- ERCOT 2025固定集成未超过公平pooled XGBoost，盈利优势不成立；
- 更低MAE没有稳定转化为更高净收益。

### 9.2 禁止

- 不把“完整基线12/12”扩大为“胜过所有基线”，因为LEAR只覆盖两任务且胜5/8；
- 不把最低MAE写成最高利润；
- 不把LOMO和all-market部署实验混称zero-shot；
- 不把逐节点XGBoost或受限先知参照称为数学盈利上界；
- 不把2023开发期优势写成跨年度稳定优势；
- 不用2025结果新增结构、seed、损失、权重或阈值。

下一轮只预注册负价发生概率与条件幅度的两阶段可解释适配。完整BEMA-R、TimesFM-3适配、爬坡和

原预注册2025实验及其`no_superiority`结论保持不变。用户于2026-10-19另行开启DA尾部加权跟进研究：
只把训练期DA价格最低/最高1%样本的MAE总权重从1提高到2，其他模型腿与决策合同不变。该机制由
2023开发、2024冻结确认后才允许进行四市场2020—2024三seed重训。

跟进研究的主终点仍为ERCOT完整净收益，MAE只作解释。由于原2025结果已经观察，新的2025评价必须
明确标为post-original-test follow-up，不得回写为原实验的首次未污染测试；候选2025结果不得再用于
修改权重、结构、seed或阈值。详细证据与执行入口见
`progress/4_多市场审计与最终基线/6_阶段闭环与尾部研究入口.md`。

负价Oracle触发的两阶段可解释适配已经完成。第一版因稀有市场样本被类别等权过度放大而在源市场
验证阶段否决；第二版以周季节价格、近期负价环境和日历构造稀疏NEG-E，并用源市场非负小时1%误报
预算冻结阈值。2024 ERCOT负价召回由22.2%提高到27.8%，日均净收益点估计由73.38提高到73.65，
但配对95%区间`[-0.01, 0.70]`跨0。NEG-A继续降低负价MAE却没有追加盈利，因此否决。
详见`progress/5_尾部事件与幅度建模/2_负价事件适配器.md`。后续不再调该线性适配器，转向局部价格动态后训练。

局部价格动态后训练第一版协议与结果已合并在`progress/5_尾部事件与幅度建模/3_局部峰值幅度后训练.md`：只对DA增加
“日最高价−日中位价”结构损失，从现有强checkpoint出发冻结编码与来源融合，只更新Query Decoder和
价格头。checkpoint只由三个源市场2023选择，先执行普通MAE不恶化超过2%的守门，再最小化日峰值幅度
误差；ERCOT 2023/2024尾部和完整收益不得参与选模，2025禁止再次读取。

该v1实验已经完成。冻结epoch 1把2023/2024
ERCOT净收益分别从`377.84/73.38`提高到`400.96/82.17 USD/节点·日`，相对原Transformer的7日块
配对区间均高于0；2024仍低于逐节点稳健XGBoost的`90.69`，且正尖峰绝对召回仍为0。因此该机制保留为
“改善日内相对幅度与DA动作”的候选，不得表述为已战胜强基线或已解决极端尖峰，也不得根据ERCOT结果
继续调损失权重、学习率或轮数。

其后按同一文件中的冻结协议补做seed 1、2及事前固定的三seed逐小时
中位数集成。结果显示只有seed 0在2023和2024
均改善，seed 1由源市场规则选择epoch 0而不发生更新，seed 2两年点估计均下降；固定中位数集成的两年收益差
区间均跨0，2024点估计为负。故正式结论为“seed 0有效，但方法对初始化敏感”。该路线已经停止，不得再调权重、
学习率、轮数或seed，也不进入条件性的排序保持正尖峰幅度适配器。动作审计可用于解释seed 0：新增DA动作多数
对应真实有利价差，DA计划腿增益覆盖额外退化成本；但绝对正尖峰召回仍为0。

局部峰值损失路线关闭后，`progress/5_尾部事件与幅度建模/4_正尖峰概率路线.md`汇总了按冻结协议进行的正尖峰日级事件可预测性与概率门控检查，判断其能否仅凭日前可见信息
